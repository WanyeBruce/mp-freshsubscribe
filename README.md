# MoviePilot V2 追新订阅

v0.3.0 修复配置页标签重叠和控件间距，新增分组布局及窄屏单列显示；更新后重启 MP 并重新打开配置页即可，原有配置和订阅记录保留。

剧集、动画、电影、综艺分类追新，支持候选确认、自动订阅、续季检查和去重。

综艺规则：憨憨站点正常匹配；观众站点必须有正片标识，并排除非正片、预告、花絮、加更等条目。请在插件设置中选择实际站点和标识字段。过滤仅对本插件创建的综艺订阅生效，插件需要保持启用。

## 安装

在 MP 插件市场配置中添加本仓库地址：

```text
https://github.com/WanyeBruce/mp-freshsubscribe
```

刷新市场，安装“追新订阅”。默认只展示候选；核对后再选择自动订阅频道。

安装或升级编译版后，请重启 MP 进程／容器，让新的本机模块生效；仅重载插件不能可靠替换已加载的本机模块。

需要 MoviePilot **>=2.15.6,<3**，Linux **x86_64**，**CPython 3.12**。ARM64、Windows、macOS 或不同 Python 小版本尚不支持。使用 MP 自带的 TMDB、网络、下载器和整理配置；Bangumi 未映射条目需先配置 TMDB ID 和季度。豆瓣来源尚未接入。

安装包通过 GitHub Releases 分发，根目录只有插件入口、许可证及 x86_64 的编译模块。核心逻辑没有以原始 `.py` 文件放入公开仓库或安装包；编译不等于不可逆向。

本版本沿用 GPL-3.0。接收者可按许可证取得对应源码；请通过本仓库 Issue 联系维护者获取。源码获取和再分发权利不因采用编译包而改变，参见 `LICENSE`。

## 剧集资源偏好（v0.3.0）

启用插件后，默认作用于所有 MP 自动剧集订阅，也可选择仅本插件创建的订阅。默认顺序：60FPS → 频道偏好 → 覆盖范围 → 大小 → 原 MP 优先级。国产剧／欧美剧优先 HDR、杜比视界；日漫优先 CR／Crunchyroll／friDay。其他剧集同样优先 60FPS。杜比音效不会误认为杜比视界。

三个正则框均支持每行一档优先级，首行最高，同一行使用 `|` 表示同级；大小写不敏感，匹配资源标题、副标题、标签。60FPS 同时读取 MP 识别的 59.94／60 帧元数据；清空相应正则可关闭该项。可切换频道优先，或关闭大文件优先。大小仅在覆盖季／集数相同时比较。

**前提：MP 设置 → 下载优先级，将“资源优先级”放在第一位。** 插件不会更改全局设置；不满足前提时显示提示并跳过资源排序，追新和综艺正片过滤仍正常。

仅排序 MP 已有过滤规则通过的当前候选，未命中偏好的普通资源仍保留，供宿主后续匹配和失败回退。不等待未来资源，不自动洗版；MP 原有整季／单集匹配流程仍有先后顺序，不能保证单集优先于整季包。电影及手动下载不受此偏好影响；其他排序插件若后续修改资源优先级，可能覆盖本排序。
